#Crosshair Overlay

Приложение работает поверх всех окон (включая полноэкранные оконные режимы в играх) и вообще не жрёт FPS, так как использует нативное аппаратное ускорение (WPF C#) и прозрачность на уровне Win32 API.

## Фичи
- **Абсолютная невидимость для кликов**: Оверлей кликабелен "насквозь" благодаря системному флагу `WS_EX_TRANSPARENT`. Ты даже не заметишь, что поверх игры висит окно.
- **Настройка**: Меняй длину линий, размер зазора (gap), толщину, цвет по RGB и прозрачность через боковую панель. Всё применяется в реальном времени.
- **Контуры (Outlines)**: Добавлена обводка тенями, чтобы прицел никогда не сливался со светлыми текстурами в играх.
- **Авто-сохранение пресета**: Профиль сохраняется в `config.json`. При следующем запуске все настройки уже подгружены.

## Как запустить / собрать
Проект написан на **C#** с использованием классического **WPF** (.NET 8.0).

Если у тебя установлена **Visual Studio 2022**:
1. Открой `CrosshairOverlay.csproj`.
2. Нажми **Start (F5)**.

Если через терминал/консоль (нужен установленный .NET SDK):
1. Открой папку с проектом.
2. Введи `dotnet run` и наслаждайся.

Буду рад любым пул-реквестам или идеям!
